# Instrucciones del agente

Leer primero `docs/REGLAS-NARRATIVAS.md`; después seleccionar la habilidad pertinente bajo `.agents/skills` y sus referencias. No escribir ni cambiar capítulos aprobados o registros de continuidad sin permiso. Nunca fingir que se leyó una fuente no disponible ni que un comprobador automático se ejecutó. Distinguir canon, inferencia, propuesta y continuidad alternativa aprobada. Se deben revisar las instrucciones de terceros antes de ejecutar scripts o herramientas.
